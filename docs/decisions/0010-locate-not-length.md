# 0010 · 인용은 길이로 재지 않는다 — 자리가 찾아지는지로 잰다

- 날짜: 2026-09-11
- 상태: 채택 · [0003](0003-no-staged-failures.md) 의 게이트 조건 ③ 을 바꾼다

## 맥락

게이트 조건 ③ 이 막으려던 것은 「값만 달랑 인용하면 어느 글 어느 자리인지 모른다」였다.
재는 방법은 **값 외 문맥 3자 이상**이었다. 그 3 은 실측에서 나온 값이라 감은 아니었다.

그런데 **재는 축 자체가 대리 지표**라는 지적이 나왔다.
묻고 싶은 건 길이가 아니라 「이 인용으로 자리가 찾아지나」고, 그건 **세면 된다.**

## 쟀다 — 모델 호출 0회

`node bench/gate-rules.js` 로 저장된 주장을 다시 걸었다.

**실제 flow 데이터 · 주장 33건**

| 규칙 | 통과 | 폐기 | 자기문서 모호 | 귀속 확인불가 |
|---|---|---|---|---|
| 옛 규칙 · 값 외 문맥 ≥ 3자 | 30 | 3 | **1** | **1** |
| A · 그 글에 한 번만 | 30 | 3 | 0 | 0 |
| B · A + 문맥 ≥ 1자 | 30 | 3 | 0 | 0 |
| C · 옛 규칙 + A | 28 | 5 | 0 | 0 |
| **D · 자기문서 유일 + 문맥 ≥ 1자** | **31** | **2** | **0** | 1 |

갈리는 인용 넷을 보면 **옛 규칙이 정확히 반대로 판정했다.**

```
"배포 3회"     그 글에 두 번   → 옛 규칙 통과   ❌ 모호한데 통과
"p95 320ms"   다른 글에도     → 옛 규칙 통과   ❌
"4시간"        한 번뿐         → 옛 규칙 폐기   ❌ 명확한데 폐기
"47회면"       한 번뿐         → 옛 규칙 폐기   ❌
```

`"47회면"` 이 잘린 건 짧아서가 아니라 **기준이 엉뚱한 걸 재고 있어서**였다.

**합성 원문 58건에서는 다섯 규칙이 전부 같았다.** 이 차이는 실제 flow 데이터에서만 드러났다.

## 결정

**D 를 채택한다.**

- 조건 ③ = **그 글에서 한 번만 나온다** + 값 외 1자 이상(인용이 값 문자열과 같은 경우만 막는다)
- 같은 문장이 **다른 글에도** 있으면 → 버리지 않고 **그 글들의 제목을 화면에 적는다**

## 왜 다른 글 중복을 버리지 않나

`"p95 320ms"` 는 회의록과 인덱스 글 **양쪽에 실재한다.** 가짜 인용이 아니라 어느 쪽인지 못 가릴 뿐이다.
버리면 참인 주장을 잃는다. [0006](0006-do-not-delete-what-the-model-split.md) 과 같은 방식으로 **등급을 적는다.**

> 같은 문장이 「[회의록] 릴리스 판정」에도 있습니다 — 어느 글에서 온 값인지 가리지 못했습니다.

## 곁들여 확인한 것

`"배포 3회"` 가 그 글에 두 번 나왔던 것은 표를 셀마다 개행으로 끊던 때의 본문 때문이었다.
[0008](0008-tables-become-rows.md) 로 행을 이은 뒤에는 `배포 · 3회` 가 되어 중복이 사라진다.
**두 결정이 같은 방향으로 맞물렸다.**
