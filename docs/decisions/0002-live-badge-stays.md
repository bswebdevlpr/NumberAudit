# 0002 · 라이브 배지는 남기고, 저장본과의 차이는 푸터로 내린다

- 날짜: 2026-09-10
- 상태: 채택

## 맥락

화면은 저장된 스냅샷을 먼저 그리고, 열릴 때 `/api/audit` 으로 실제 감사를 다시 돌려 갈아 끼운다.
배지가 그 결과를 보고한다. 첫 문구가 이랬다.

```
지금 감사 · gemini-3.1-flash-lite · 19건 · 8.6초 · 저장본 28건
```

읽는 사람이 제일 먼저 만나는 자리에서 **아무도 안 물어본 숫자 차이부터** 말한다.
맥락 없이 보면 결함 고지로 읽힌다. 배지를 빼자는 이야기가 나왔다.

## 결정

**뺀다 → 아니다. 남긴다.** 대신 말하는 순서를 바꾼다.

```
방금 다시 감사했습니다 · 19건 · 10.9초
```

저장본과의 차이는 그 숫자가 실제로 적히는 곳(푸터)으로 내리고, **이유와 붙여서** 적는다.

> 지금 화면은 방금 돌린 결과입니다. 라이브는 함수 상한(60초) 안에 들어와야 해서 빠른 모델로 돌고,
> 저장본은 상위 모델로 만든 것이라 28건입니다.

모델명·호출 횟수는 배지 툴팁으로 내렸다.

## 왜 빼면 안 되나

배지가 **이 페이지가 살아 있다는 유일한 증거**다.
없으면 화면 전체가 미리 만들어 둔 JSON 을 예쁘게 그린 것과 구분되지 않는다.
이 도구가 지금도 플로우를 부르고 모델을 돌린다는 것은 **정적 스냅샷으로는 증명되지 않는다.**

## 결과

배지가 데스크톱 폭 820~1920px 전부에서 안 잘린다(측정).
숨긴 게 아니라 순서를 바꾼 것이라, 저장본과 다르다는 사실은 그대로 화면에 남아 있다.
