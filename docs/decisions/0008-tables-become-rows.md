# 0008 · 표는 행 단위로 잇는다 — 융합과 과분할 사이

- 날짜: 2026-09-11
- 상태: 채택

## 맥락

데모 데이터는 전부 API 로 심어 `htmlContent` 가 비어 있었다. 정제 단계가 화면에서 일을 안 했다.
그래서 **에디터로 직접 쓴 글**을 하나 심었다 — 제목 · 글머리 목록 · 표를 서식으로 지정한 글이다.

`outContent` 가 이렇게 왔다.

```
이번 주 숫자코드리뷰 평균 대기 6시간 배포 3회, 롤백 1회
어떻게 쟀나리뷰 대기는 영업일 기준, 최근 2주 평균입니다.
항목값코드리뷰 평균 대기4시간배포3회
```

`</h2>` 와 다음 블록이 붙고, **표는 셀 경계가 하나도 안 남는다.**

`content`(COMPS JSON)에는 `SHAPE: "TABLE"` 이라는 표식이 오지만 `CONTENTS` 는 이미 뭉개져 있다.
셀 경계가 남아 있는 곳은 `htmlContent` 뿐이다.

## 어느 쪽으로 풀어도 한 번 졌다

| 방식 | 모델이 낼 인용 | 게이트 | 결과 |
|---|---|---|---|
| `outContent` 그대로 | `코드리뷰 평균 대기4시간배포3회` | **통과** | 융합된 문자열이 원문에 실재하므로 오염된 주장이 판정까지 올라간다 |
| 셀마다 개행 | `4시간` | **폐기** | 값이 홀로 남아 문맥 하한(값 외 3자)에 걸린다 |

두 번째가 실제로 났다. 표 값 2건(`4시간` · `3회`)을 잃었다.

## 결정

**행을 한 줄로 잇는다.**

```
코드리뷰 평균 대기 · 4시간
배포 · 3회
```

값 옆에 그 값이 무엇인지가 남고, 그게 인용의 문맥이 된다.

## 결과

```
✗ 전:  4시간  인용 "4시간"                   → 폐기 · 문맥 없음 (값 외 2자)
✓ 후:  4시간  인용 "코드리뷰 평균 대기 · 4시간"  → 통과
```

두 값 모두 통과했고, 모델이 다른 블록에 적힌 측정 방법(`영업일 기준, 최근 2주 평균`)까지 찾아 붙였다.

**표본은 표 하나다.** 병합 셀 · 중첩 표에서 어떻게 되는지는 안 쟀다.
