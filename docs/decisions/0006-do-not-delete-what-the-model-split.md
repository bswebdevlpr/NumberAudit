# 0006 · 모델이 조건을 갈랐다고 항목을 지우지 않는다

- 날짜: 2026-09-11
- 상태: 채택

## 맥락

[0004](0004-context-sameness-goes-to-the-model.md) 로 조건 판단이 모델에게 갔다.
모델이 조건을 잘못 가르면 **진짜 불일치가 「조건이 달라서요」로 덮인다.**

지금 이 도구는 오탐 쪽으로 치우쳐 있다 — `47회 → 3회` 같은 개선 전후를 갈림이라 부른다.
모델 판단을 넣으면 반대로 기운다.

## 결정

묶되 **버리지 않는다.** 조건이 갈린 값도 화면과 업무 본문에 남기고 등급만 달리 적는다.

```
■ 조건이 달라 견주지 않은 값 1건
- 280ms 「인덱스 추가 + N+1 제거 — 댓글」 · 방법: 캐시 워밍 후 3회 평균
  ↑ 잰 조건이 서로 달라 값을 견주지 않았습니다. 같은 조건이라면 알려 주세요.
```

2차 판정이 「그룹 밖 대조」라고 등급을 적는 것과 같은 방식이다.

## 이유

오탐은 사람이 보고 넘기면 된다. **미탐은 도구를 쓸 이유를 없앤다.**
사람이 뒤집을 수 있게 두는 것이 넘긴 판단을 되돌릴 유일한 통로다.

## 리뷰에서 하나 더 나왔다

첫 판은 **조건이 안 적힌 값까지** 「조건이 달라 견주지 않았다」로 분류했다.
그건 조건이 「다른」 게 아니라 「모르는」 것이다. 화면이 사실과 다른 말을 하고 있었다.

이름 붙은 조건이 둘 이상일 때만 세도록 고쳤다. 조건 미기재 값은 1차 「근거 없음」이 따로 본다.
